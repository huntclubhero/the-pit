## Top 3 seams SOLID (coverage)
1. Odds asymmetry (20:1) x cost-to-move cap x per-address sub-cap: SOLID. Global OI cap bounds sum(longStake+shortStake) <= cap <= maxPayoutCap; any position's payout <= its total escrow; summed across a sybil's wins the extracted loserStakes are all part of that same global OI, so aggregate attacker payout bounded by the cap regardless of odds. Odds shift WHO posts what, never the ceiling. Sub-cap partitions global OI cleanly.
2. Fee-split (4-way push) x pull-payment credits: SOLID. Fill pushes only fees to the 4 trusted immutable recipients; stakes stay escrowed = OI added; settle/unwind CREDIT parties (pull) while only fee is pushed to distinct addresses, so credits and pushes never target the same slot, no double-count/race; remainder-to-treasury sums to fee exactly.
3. Points/jackpot x odds x fee-split: SOLID, negative-sum by construction. Only 25% of every fee reaches the pot; points are notional-proportional and minting requires paying that notional's fee; a sole self-farmer nets ~-1.7 fee-units/fill-unit. Odds make farming WORSE (points key off small taker notional while high-odds maker pays fee on large notional: ~10x lower points/jackpot-dollar at 20:1). (NOTE: this is jackpot farming from the attacker's OWN fees being negative-sum; red-casino's H-J1 attacks the SEEDED/standing pot which is a different, positive-EV vector.)
