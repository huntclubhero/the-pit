Auditor: re-listing (Fable) | 2026-07-23 | Verdict: W2-14 fully closes; W2-10 + W2-13 close their PRIMARY finding, bounded residuals. No CRIT/HIGH.

## W2-14 (openingAllowed vs served price): VERIFIED CORRECT, no survivor
_peekPrice (OracleRouter:634-650) faithfully mirrors checkPrice's served OK price in all four devFail branches (checked >=3 serve / ==2 cooldown-elapsed predict / ==2 in-window deny / ==0 fresh deny). Common non-fallback path identical to old raw median. During cooldown-before-fallback _peekPrice returns COOLDOWN so openingAllowed denies (NEW deny vs old, but strictly fail-safe; settlement paused anyway; fillOffer is the only caller). No spot-vs-served mismatch. Clean.

## FINDING 1 (W2-10 residual, LOW-MED, mechanism HIGH / exploit LOW): market created DURING source deviation gets no fallback seed
isListable (OracleRouter:669-692) never calls _evaluate so does NOT require live source agreement. createMarket gates on isListable then primeFallback best-effort. primeFallback (610-623) no-ops when sources disagree (_evaluate!=OK or devFail -> break before any ring write). So a market listed while sources deviate launches with an EMPTY ring = the permanent-COOLDOWN forced-unwind free option W2-10 targets. Self-refute: self-heals once 3 agreeing checkPrice prints accumulate (every fill/settle pushes one; anyone can primeFallback later); only bites a market seeing <3 agreeing blocks before a sustained from-birth deviation. Narrow, expensive to force.

## FINDING 2 (W2-10 new weakening, LOW): primeFallback collapses median-of-3 into ONE read, permissionless anytime
primeFallback loops AGREED_PRINTS over a pure-view _evaluate with no state change between iterations (612-621), filling all 3 ring slots with the SAME median = zero temporal diversification (checkPrice alone needs a skew to persist across 3 separate prints; primeFallback sets the whole fallback from ONE block). _breakers is token-keyed, never cleared, primeFallback has no listing/auth guard, so an attacker can pre-seed a skewed ring BEFORE market creation; createMarket only overwrites if sources agree at creation (Finding 1), else the pre-seed persists. Self-refute: every write requires _evaluate OK && !devFail (sources must AGREE), so A_MAJOR's independent-feed requirement blocks skewing; single-source B/C never serves fallback (devFail always false); only live surface is a multi-source pool-tier token where moving all sources in-band is the pool manipulation the cost-to-move cap already bounds. Modest robustness loss, not a standalone profit vector.

## FINDING 3 (W2-13 opt-in / sources[0]-only, LOW/info): cross-check does NOT bind an adversarial owner
_trackedPoolsCoveredBySource (700-714) enforces readsPool ONLY on sources[0] and treats a revert (non-ISettlementPoolSet) as covered (catch->true). Gaps: (a) opt-in: a malicious owner sizes the cap to pools the settlement source never reads by configuring a non-conforming adapter, skipping the check; (b) sources[0]-keyed: if sources[0] is a non-pool-set adapter (Chainlink first) the catch fires and returns covered without validating the actual CrossPool at sources[1]. Catches only HONEST misconfig with a conforming CrossPool at sources[0]; no guarantee vs compromised owner. Self-refute: consistent with the disclosed owner-trust boundary (owner controls adapter config, bounded by timelock not by listing math); docstring is honest that a non-exposing source is treated as covered.

## Recommended hardening (optional, not blockers)
1. createMarket revert/retry if primeFallback leaves ringCount<AGREED_PRINTS on a fallback-serving tier (closes Finding 1).
2. Cap primeFallback to advance ringCount by at most 1 per call (match checkPrice) to restore median-of-3 temporal diversification (closes Finding 2).
3. Iterate ALL sources in _trackedPoolsCoveredBySource and require at least one positive coverage confirmation rather than treating revert as covered (partially closes Finding 3).
