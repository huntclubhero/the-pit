# Wave 3 Re-Audit: composition (fix-x-fix / fix-x-feature seams)
Auditor: re-composition (Fable) | 2026-07-23 | Verdict: NO CRITICAL cross-fix drain; conservation/escrow survive composition. Several real seams, strongest F1 + F2 (both blunt a wave-2 mitigation using an existing feature/fix).

## Findings
### F1 (MEDIUM, HIGH conf): timelock x MIN_SOURCES=3 x feedMaxStaleness bricks major settlement for the whole timelock window on a routine feed migration
W2-3 hands ChainlinkAdapter/router to a 2-day TimelockController, so setFeed/setSources are 2-day-delayed. A_MAJOR requires 3 fresh sources (MIN_SOURCES=3, _evaluate returns STALE when count<3). Chainlink feeds get deprecated/migrated in normal ops; when one of a major's 3 goes stale, count drops to 2 -> STALE -> checkPrice non-OK -> settlement BLOCKED, and the only remediation (repoint via setFeed) is now 2-day-timelocked. A benign feed outage freezes settlement on that major ~2 days; live positions risk the expiry+24h neutral forced-unwind that denies an ITM winner. The timelock (fix for a MALICIOUS swap) directly fights the liveness invariant W2-10/W2-12 preserve. Guardian pause cannot substitute (blocks settlement, does not fix a feed). FIX: configure >MIN_SOURCES feeds per major (losing one keeps quorum), and/or a shorter break-glass delay for setFeed. Magnitude (feed migrations routine, not adversarial) makes it more than theoretical.

### F2 (MEDIUM, HIGH conf): open bond x permissionless createMarket is front-runnable and self-defeating per token
openBondBps immutable per market, baked at creation from factory.openBondBps (DEFAULT 0), setOpenBondBps affects FUTURE markets only, createMarket permissionless + one-per-token. The exact actor W2-9 targets calls createMarket for the hot token FIRST while factory.openBondBps is still 0, baking openBondBps=0 immutably, then Sybil-monopolizes for free; governance can never raise it on that market, and global arming is itself behind the 2-day timelock (F1). So W2-9 only protects tokens whose markets are created AFTER global arming and NOT by the monopolizer. FIX: arm the bond at deploy (OPEN_BOND_BPS>0), or disclose W2-9 as still-open for attacker-created markets. (Corroborates re-bond F1.)

### F3 (LOW-MED, MED conf): primeFallback permissionless anytime, collapses ring temporal diversity + self-tension
primeFallback (:610-623) is permissionless, callable anytime (not just listing), fills all 3 ring slots with ONE instantaneous median, resets failedRounds/cooldownUntil each iteration. (a) collapses temporal diversity: a caller picks a favorable transient instant then forces sustained deviation, baking that single value as settlement fallback. (b) self-tension: resetting the breaker on each brief agree window can keep failedRounds from reaching FALLBACK_AFTER_ROUNDS, so fallback never triggers and the position is pushed to the expiry+24h neutral unwind, PRESERVING the free-option W2-10 was written to close. Marginal over the A1/checkPrice-ring vector, TWAP timing edge small. FIX: cap primeFallback to one print per call (distinct blocks), or gate to factory/first-listing only. (Corroborates re-listing.)

### F4 (LOW, HIGH conf): nonrefundable bond kept on a protocol-caused neutral forced-unwind. On oracle-failure unwind both parties get stake back but the taker already irrevocably lost the bond for a non-fault protocol-side event. Bounded (<=5% OI), only when armed. Fairness doc note.

### F5 (INFO/LOW, MED conf): mean-liquidity basis is a DIFFERENT SCALE than wave-1 balanceOf, so cap coefficients may no longer bound payout. consultMeanQuoteReserve returns virtual reserve (L/sqrtP or L*sqrtP), not raw balanceOf; aggregateDepthFloorUsd + costToMoveCoeff were tuned against balanceOf; unless re-derived, maxMarketPayoutCap can be mis-sized (over-sized -> W2-1's max_payout<=costToMove/SF silently violated again). Governance re-tuning + a regression assert cap<=costToMove/SF on the new basis. (Corroborates re-jit.)

### F6 (INFO): seed() pot overstates winnable value (seed excluded from drip until organic fees drip in; pot() includes seed): UX/marketing integrity note. Weekly draw for epoch N-1 syncs inflow at request AND fulfill so epoch-N fees in that window leak into epochInflow[N-1]; bounded to that window, NOT profitably exploitable (adding X inflow costs ~4X in fees, unlocks 0.5X). (Corroborates re-jackpotdrip, bounds it lower.)
